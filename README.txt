UPLOAD INSTRUCTIONS
1. Upload index.html, style.css, script.js, and data.json to the root of your GitHub Pages repository.
2. Keep avatar.png and my.cv.pdf.pdf in the same root folder.
3. Create a folder named videos and put your capstone clip inside as greenwifi-demo.mp4.
4. If your clip has a different name, edit the GreenWifi project's "video" value in data.json.
5. Edit your school name, achievements, project details, and any unimplemented AI features in data.json before publishing.
6. For local testing, use VS Code Live Server. data.json may not load if you double-click index.html directly.
